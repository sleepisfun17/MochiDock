Inspiration (no code or artwork included)

The idea for MochiDock came from coucou (https://github.com/Louis-CFM/coucou),
a notch companion for macOS; MochiDock is a light take on the idea for Windows.
Some card layouts were also influenced by Oyenza Studio
(https://github.com/lucacadalora/oyenza-studio). Neither project's code or
artwork is part of MochiDock, so their licences do not apply to it.

Wireless device batteries (MochiDock/Services/DeviceBattery, MochiDock.Core/DeviceBattery.cs)

The code is MochiDock's own. Device facts come from:
- BatteryTray by qu1ncky (MIT): the Rongyuan/Monsgeek receiver status query
  and the list of Rongyuan receiver IDs, which BatteryTray read from the
  official ATTACK SHARK web driver (qmk.top).
  Source: https://github.com/qu1ncky/BatteryTray
- LAMZU Aurora web driver (https://lamzu.net, read for interoperability, no
  code included): the LAMZU product IDs, model names, cable and receiver IDs
  (Config/env-models.json) and the battery request and reply layout.
- Wireless-Device-Battery-Monitor by krisgfx9 (GPL-3.0), consulted for
  protocol facts only (no code or lists included): report layouts, the Phone
  Link Start-menu companion card layout, and the Windows 11 Widgets-button /
  right-to-left taskbar placement behaviour.
  Source: https://github.com/krisgfx9/Wireless-Device-Battery-Monitor
- Solaar (GPL-2.0): the Li-ion voltage-to-percent table used for Logitech
  HID++ voltage readings. Source: https://github.com/pwr-Solaar/Solaar

Online data sources (no code included)

- Weather and the weather used for prayer times: Open-Meteo
  (https://open-meteo.com), data under CC BY 4.0.
- Place search: OpenStreetMap Nominatim. Data (c) OpenStreetMap contributors,
  ODbL 1.0 (https://www.openstreetmap.org/copyright).
- Exchange rates: ExchangeRate-API (https://www.exchangerate-api.com),
  fawazahmed0/exchange-api (through jsDelivr), Yahoo Finance, and optionally
  Open Exchange Rates with your own key.
- Prayer times: AlAdhan (https://aladhan.com). Lyrics: LRCLIB
  (https://lrclib.net). Weather fallback: wttr.in.
